# Комбинированный генератор псевдослучайных чисел (Лабораторная работа №8)

Учебный проект на C++, реализующий комбинированный аддитивный генератор псевдослучайных чисел и статистическую проверку равномерности его распределения.

## 📌 Задание (Вариант 8)
Скомбинировать два датчика: стандартную функцию `rand()` и последовательность Фибоначчи как сумму по `mod RAND_MAX`. Подсчитать частоты попадания сгенерированных чисел в каждый из интервалов длиной `10 000` при объеме выборки `500 000`.

## ⚙️ Описание алгоритма и структура проекта
Проект разделен на три модуля для многофайловой сборки:
* **`my_lab.h`** — заголовочный файл с прототипами функций и константами (`TOTAL_SAMPLES = 500000`, `INTERVAL_LEN = 10000`, верхний предел `MY_MAX = 32767`).
* **`my_lab.cpp`** — реализация генератора `generateCustomRand()`, где хранятся статические переменные ряда Фибоначчи (`f1`, `f2`) и вычисляется их сумма со стандартным `rand()` по модулю `MY_MAX + 1`, а также функции определения номера интервала `getIntervalIndex()`.
* **`main.cpp`** — точка входа: инициализация генератора текущим временем, сбор статистики по 500 000 итерациям и вывод частот на экран.
